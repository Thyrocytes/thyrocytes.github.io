Retirement Exploit

History

As I was messing around in a FydeOS v18 (Chrome v120) virtual machine, I was trying to disable Lightspeed Filter Agent with Allow access to file URLs and LightSPED Killer Agent.

Blobby-Boi's method was patched, even for older Chrome versions, so I resorted to chrome://serviceworker-internals.


However, I had noticed something interesting: the Unregister and Inspect buttons showed a little "Running..." label even if they did nothing.

I scrolled to the bottom, and I also noticed that flipping "Allow access to file URLs" shows a little "Unregister" and "Stop" menu in ServiceWorker internals.


Out of randomness (I don't remember the following parts exactly), I started spam-flipping the switch as I had done that prior to me finding a killer exploit.

I clicked "Unregister" also out of randomness. Suddenly, Lightspeed Filter Agent's worker was permanently removed! I flipped the switch again and that revived Lightspeed.

I recorded a small little video out of it, posted the exploit details to the TN Discord (#kajigs-discussion), then I guess today I'm writing this page.


How to Retirement

1. Side-screen chrome://serviceworker-internals and an extension details page.


2. Scroll to the bottom in chrome://serviceworker-internals.


3. Flip the switch labeled Allow access to file URLs. For older Chrome versions, try spam-flipping the switch to increase the time window.

If there's a piece of text saying "Changes to this setting will be applied once Chrome restarts" for more than a second then unfortunately this exploit will not work for you.

If there is no "Allow access to file URLs" switch, try a different extension or cry in a corner.


4. Find the "Unregister" button in ServiceWorker internals then immediately click it.


5. The extension worker entry should be permanently removed! To install it again, flip "Allow access to file URLs" once more.

Repeat step 3 if the extension worker hasn't been removed.
